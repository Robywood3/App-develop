# Repository App-develop

Contiene tre progetti separati:

- `casa-app/`: interfaccia della casa (Home Assistant + FastAPI + React). Prima di lavorarci leggi
  `casa-app/CLAUDE.md` e `casa-app/docs/architettura.md`: le loro regole valgono per tutto `casa-app/`.
- `casa-clima/`: prototipo Node.js con integrazioni scritte da zero. Superato da `casa-app/` (RNF-05): non estenderlo.
- `app/`: app webOS per le telecamere EZVIZ sulle TV LG.
